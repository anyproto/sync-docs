# any-sync docs

Source for the **any-sync** protocol documentation, published at **https://sync.any.org**.

`any-sync` is an open-source protocol for high-speed, peer-to-peer synchronization of
end-to-end-encrypted, user-owned channels (spaces).

Built with [Astro Starlight](https://starlight.astro.build/). Documentation content lives
in `src/content/docs/`.

## Local development

```sh
npm install
npm run dev      # local preview
npm run build    # static build → ./dist
```
